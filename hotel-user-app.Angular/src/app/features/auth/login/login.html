Login

This page will let a customer sign in with the JWT token returned by your .NET API. It is now connected to POST /api/Auth/login.

  • Customer enters email and password.
  • Angular sends credentials to your API.
  • API returns JWT token.
  • Angular stores the token and uses it for protected requests.
